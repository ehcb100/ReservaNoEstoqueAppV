# 📋 Papelaria Comandas

O **Papelaria Comandas** é um sistema web desenvolvido para facilitar o registro, o acompanhamento e a organização dos serviços realizados em uma papelaria. A plataforma permite gerenciar solicitações de impressões em preto e branco e coloridas, cópias de documentos, encadernações, plastificações e outros serviços.

O sistema também possibilita registrar informações dos clientes, responsáveis pelo atendimento, centros de custo, formas de pagamento, valores e horários, contribuindo para uma rotina de trabalho mais organizada e eficiente.

Entre seus recursos, destacam-se o acompanhamento do status das comandas, os lembretes periódicos para serviços pagos ainda não concluídos e a geração de relatórios em PDF para consultar os atendimentos finalizados.

O projeto busca reduzir esquecimentos, facilitar o controle das demandas e promover um ambiente de trabalho mais colaborativo e organizado.
